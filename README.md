# SWYNEX Task 2: Basic Cloud Deployment

## Project Overview
This project is a simple, interactive website that introduces cloud computing, its service models, and its benefits.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Introduction to cloud computing
- Explanation of IaaS, PaaS, and SaaS
- Benefits of cloud computing
- Interactive button that displays random cloud computing facts
- Responsive website design

## Deployment
The website is hosted using Netlify's free hosting option.
